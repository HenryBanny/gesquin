⚙️ Connexion GitHub

Les données seront sauvegardées dans un fichier JSON de votre dépôt GitHub.
Créez un Personal Access Token sur github.com/settings/tokens avec la permission repo.

💡 Comment ça fonctionne :
À chaque modification (facture, stock, client…), les données sont automatiquement sauvegardées dans votre dépôt GitHub sous forme de commit. Au chargement, elles sont rechargées depuis GitHub — accessibles depuis n'importe quel appareil.
